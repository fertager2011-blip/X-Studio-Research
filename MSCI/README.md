# MSCI — X3: Terran Conflict 3.4

## Scope
Справочник команд MSCI с приоритетом точных данных для X3TC 3.4.

## Источники
Список конкретных источников и их версий вести в [Sources.md](Sources.md). Справочники других версий/игр считать кандидатами, пока не подтверждена совместимость.

## Требования к записи команды
- точное отображаемое имя;
- параметры и типы, если подтверждены;
- описание и ограничения;
- command ID только если источник прямо подтверждает его, с указанием системы ID;
- версия игры/редактора и источник;
- статус подтверждения.

**Не смешивать MSCI command IDs с `COMMAND_TYPE_*` слотами/ID команд движка.**
