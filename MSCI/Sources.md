## Правила использования источников
- Для точной команды предпочтительны официальные/версионно подходящие материалы и файлы игры.
- Указывать контекст версии. Если источник не уточняет версию/патч, помечать это ограничением.
- Сниппет поисковика не равно полной проверке страницы.
- Не считать сведения о меню, появившиеся в TC 2.5+, автоматически подтверждёнными для любой версии без проверки.
- Не смешивать MSCI command IDs с `COMMAND_TYPE_*` command-slot IDs.
