# Confirmed Findings

Только подтверждённые наблюдения. Для каждого пункта: ID, утверждение, источник/файл, версия, метод проверки, ограничения.

## F-001 — Script Editor является встроенным редактором TC
- **Утверждение:** X3: Terran Conflict содержит встроенный Script Editor (Script Editor / Manual Ship Computer Interface).
- **Источник:** X3 Wiki, статья Script editor — https://x3.solasistim.net/index.php/Script_Editor/
- **Контекст:** статья относится к TC; опубликована/редактировалась в 2013 году.
- **Метод:** просмотр статьи.
- **Ограничения:** источник подтверждает назначение встроенного редактора, но не внутреннее устройство стороннего X-Studio v1.08.

## F-002 — Встроенный Script Editor активируется через имя пилота
- **Утверждение:** активация SE в TC производится вводом имени пилота `Thereshallbewings` (с заглавной T и двойной l); после правильного ввода имя не изменяется, появляется доступ к редактору.
- **Источник:** Egosoft FAQ — https://www.egosoft.com/support/faq/faq_answer_en.php?answer=945
- **Метод:** поисковый результат официальной FAQ, сверенный с X3 Wiki Scripts & Mods — https://x3.solasistim.net/index.php/Scripts_%26_Mods/
- **Ограничения:** полная страница FAQ не открылась в исследовательском инструменте; факт подтверждается поисковым текстом FAQ и независимой wiki-страницей. Не относится к X-Studio как внешнему редактору.

## F-003 — Встроенный редактор позволяет запускать, редактировать и создавать скрипты
- **Утверждение:** встроенный SE позволяет просматривать запущенные скрипты, запускать их вручную, редактировать и писать собственные.
- **Источник:** X3 Wiki Scripts — https://x3.solasistim.net/index.php/Scripts/
- **Метод:** просмотр страницы.
- **Ограничения:** это описание встроенного SE, не функциональности X-Studio v1.08.

## F-004 — MSCI — язык скриптов X3
- **Утверждение:** Script Editor использует MSCI (собственный язык скриптов серии X).
- **Источник:** X3 Wiki Script editor — https://x3.solasistim.net/index.php/Script_Editor/
- **Метод:** просмотр страницы.
- **Ограничения:** общая характеристика языка; не является каталогом команд и не подтверждает идентификаторы команд для TC 3.4.
