# Loading Process

## Цель
Проверить, как X-Studio Script Editor v1.08 читает и интерпретирует файлы X3TC 3.4.

## Исследуемые стадии
- выбор/открытие файла;
- чтение и разбор XML;
- обработка `sourcetext` и/или `codearray`;
- отображение данных в интерфейсе;
- обработка ошибок/неполных файлов.

## Статус
Внутренние функции и названия процедур загрузки не подтверждены. Не использовать предполагаемые имена как факты.

## Протокол
Для каждой проверки: входной файл, версия редактора, наблюдаемое поведение, лог/ошибка (если есть), повторяемость, вывод и уровень уверенности.
