# `$MARS.Config[n]` — индексный справочник по исходному образцу

## Источник и ограничения

- Исходный XML: `plugin.gz.mars.config_modified(1).xml` (локальная копия).
- XML разобран; таблица извлечена из 2246 строк `sourcetext` автоматическим поиском точных обращений `$MARS.Config[n]`.
- Здесь индекс и строки приведены как фактически обнаруженные. Назначение настройки **не выводится только из номера**.
- «Запись» определена синтаксически: строка начинается с `$MARS.Config[n] =`. Другие формы изменения через переменные/команды этим простым классификатором могут не выявляться.
- Пробелы в отображении нормализованы; исходные XML токены не переписывались.
