# X3TC 3.4 — Практический тест двух колонок в Custom Menu

## Цель
Проверить в игре X3: Terran Conflict 3.4 позиционное форматирование текста custom menu, добавленное в патче 2.5. Рабочие файлы MARS не изменяются.

## Источник синтаксиса
Egosoft Community Wiki, “Creating beautiful menus in X3: Terran Conflict”:
- текст меню может быть массивом: `ARRAY('PosCol1', 'text1', 'PosCol2', 'text2', ...)`;
- позиции колонок — целые числа;
- `1` позиционирует текст слева, `-1` — справа;
- предел позиции для normal menu указан как 346, для info menu — 858;
- текстовые значения колонок должны быть строками.
Источник: https://wiki.egosoft.com/X3%20Wiki/02.%20X3%3A%20Terran%20Conflict/Scripts%20and%20Modding/Tutorials/Creating%20beautiful%20menus%20in%20X3%3A%20Terran%20Conflict/

## Минимальный тестовый скрипт (собрать в X-Studio Script Editor)

Назначение: создать меню с информационными строками и выбираемыми строками, в каждой — левое и правое поле.

1. Создать новый скрипт с уникальным именем, например `test.menu.columns` (имя тестовое, не существующий ID игры).
2. Создать `$menu` командой `create custom menu array`.
3. Создать `$row1` командой `create new array, arguments=1, 'LEFT: Basic row', -1, 'RIGHT: ON', null`.
4. Создать `$row2` командой `create new array, arguments=1, 'LEFT: Long label test', -1, 'RIGHT: ACTIVE', null`.
5. Создать `$row3` командой `create new array, arguments=1, 'LEFT: Empty right test', -1, '', null`.
6. Добавить `$row1` в меню командой `add custom menu info line to array $menu: text=$row1`.
7. Добавить `$row2` в меню командой `add custom menu info line to array $menu: text=$row2`.
8. Добавить `$row3` в меню командой `add custom menu info line to array $menu: text=$row3`.
9. Создать `$select1` командой `create new array, arguments=1, 'LEFT: Select item A', -1, 'RIGHT: VALUE 1', null`.
10. Добавить `$select1` как selectable menu item с return value `'test_A'`. (В X-Studio выбрать команду `add custom menu item to array`; её text-параметр получает `$select1`, return value — строку `'test_A'`.)
11. Создать `$select2` аналогично, текст `LEFT: Select item B` и `RIGHT: VALUE 2`, добавить с return value `'test_B'`.
12. Открыть меню командой `open custom menu`, title `Two-column test`, description `null`, option array `$menu`.
13. Проверить возвращённое значение: ESC должен вернуть `-1`, выбор — соответствующий return value (`test_A` или `test_B`).

## Проверки в игре
- [ ] Левые поля стоят слева, правые — справа.
- [ ] Позиции колонок сохраняются между строками.
- [ ] Информационные строки отображаются корректно.
- [ ] Выбираемые строки отображаются корректно и выбираются.
- [ ] ESC возвращает -1.
- [ ] Длинная подпись не перекрывает правое поле.
- [ ] Пустое правое поле не ломает строку.
- [ ] Проверить значения колонок (1 и -1) и не менять их между строками.

## Важные замечания/ограничения источника
- Вики описывает смещения/позиции, а не пиксельные координаты; не предполагается, что -1 гарантирует конкретный пиксельный край.
- Если в меню используются несколько групп с разными позициями колонок, в tutorial описан bug: группа, видимая только после прокрутки, может изменить позиционирование колонок. Поэтому в тесте используется одинаковая пара позиций во всех строках.
- Tutorial также описывает bug с дополнительным заголовком, когда первый heading имеет колонное форматирование; этот тест избегает колонного heading.
- Скрипт пока является пошаговой сборочной инструкцией, не готовым импортируемым XML. Команды должны быть собраны/сохранены через X-Studio; реальный запуск в игре не выполнен.
