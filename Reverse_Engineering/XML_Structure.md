# XML Structure — X3TC scripts

## Scope
Файлы скриптов X3: Terran Conflict 3.4, используемые в исследовании X-Studio v1.08.

## Что исследовать
- XML declaration и корневой элемент.
- Состав, порядок и атрибуты дочерних элементов.
- `<sourcetext>` и `<codearray>`: присутствие, тип содержимого, форматирование, возможные связи.
- Дополнительные элементы, комментарии и метаданные.

## Подтверждено
На текущем этапе наличие/роль отдельных элементов не фиксируется как универсальная схема без анализа конкретных исходных файлов.

## Метод
1. Собрать несколько скриптов из одной версии игры.
2. Сравнить минимальный, простой и сложный скрипты.
3. Проверить XML парсером и сохранить исходные байты для сравнения.
4. Записать примеры и наблюдения в `Findings/Confirmed.md` с указанием файлов/версий.

## Открытые вопросы
- Обязательность элементов и атрибутов.
- Порядок элементов и допустимость пропусков.
- Какие элементы редактор пересоздаёт при сохранении.
