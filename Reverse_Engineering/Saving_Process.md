# Saving Process

## Цель
Проверить, как X-Studio Script Editor v1.08 записывает скрипты X3TC 3.4.

## Исследуемые стадии
- сохранение без изменений;
- сохранение после правки текста;
- сохранение после изменения команды/параметров;
- сохранение XML структуры, кодировки, порядка элементов и форматирования;
- влияние на `sourcetext` и `codearray`;
- различия до/после сохранения.

## Статус
Алгоритм сохранения не установлен. Нужны реальные файлы и контрольные diff.

## Протокол
Сохранять исходную копию, выполнять одно изменение, сравнивать XML и байты, затем повторять для контрольных случаев.
